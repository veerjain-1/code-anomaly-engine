# Contributing to Code Anomaly Engine

First off, thank you for considering contributing to Code Anomaly Engine!

## Development Setup
1. Ensure you have Go 1.22+ and Rust 1.77+ installed.
2. Run `make build` to compile all services.
3. Run `docker-compose up` to boot the local cluster.

## Pull Request Process
1. Ensure any install or build dependencies are removed before the end of the layer when doing a build.
2. Update the README.md with details of changes to the interface.
3. You may merge the Pull Request in once you have the sign-off of the maintainers.
